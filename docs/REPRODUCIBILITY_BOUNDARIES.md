# What passing the checks means

The tests cover arithmetic, report linkage, schema constraints, coding consistency,
case dispositions, selected source-correction regressions, spreadsheet cell values
and formulas, and the byte integrity of the distributed snapshot. The numerical
algorithms are deterministic and require no random seed.

They do not independently validate the original studies, source interpretations,
completeness of literature discovery, historical appraisal judgments, causal effects,
or clinical and managerial usefulness of the proposed worksheet. A green CI check
is not an independent human review or a guarantee of a journal score.

Windows/Linux and multiple Python versions are configured for hosted CI but should
be described as tested only after their actual jobs complete successfully. A DOI
identifies an archived release; it is not a quality certificate.

Author facts, creator metadata and reuse rights must be confirmed before describing
this resource as fully FAIR or openly licensed.
