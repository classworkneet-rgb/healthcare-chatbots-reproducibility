# Corrections and reproducibility reports

Use an issue to identify the report ID, CSV, column and source location. Distinguish
extraction corrections from eligibility amendments and changes to interpretation.
Do not silently change a denominator, historical sensitivity label or claim.
Keep the stable report IDs and preserve source-access limitations.

For a proposed correction: update the authoritative CSV, run the analysis and tests,
check all affected narrative claims, and record the change. Maintainers should
regenerate the manifest only after reviewing the changed files. Regenerating a
checksum does not establish scientific validity. Never attach participant-level data,
access credentials or copyrighted publisher PDFs to an issue.
