# Citing these analytical materials

Associated article title:
**From User Experience to Organizational Value: A Critical Integrative Review of
Intelligent Chatbots in Healthcare Services**.

This repository contains the study-level data and analytical code, not a published
article record. Prepared analytical snapshot version: **1.0.0**.

The manuscript authors, publication DOI and archival repository DOI are not supplied
in the source package. They must not be inferred from a GitHub account name. Until
approved creator metadata and an archival DOI are available, identify the title,
repository URL, release/tag and full commit SHA when referring to the materials.
After creator verification, add `CITATION.cff` with the actual names/ORCIDs and the
registered version DOI. No DOI has been generated by preparing this folder.

GitHub's citation-file guidance:
https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files
